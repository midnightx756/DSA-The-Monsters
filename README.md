## Overview

DSA-The-Monster is a Unity‑based 2D game where the player runs continuously, jumps, shoots, and faces challenging bosses. The project demonstrates core game‑development concepts such as scrolling backgrounds, input handling, sprite animation, and simple AI.

## Features

- **Endless scrolling world** with parallax layers
- **Multiple enemy types** and AI behaviors
- **Boss fights** with unique patterns
- **Input system** supporting keyboard and mouse
- **Visual feedback** for shooting, jumping, and taking damage
- **Extensible architecture** for adding new mechanics
- Built with the **Universal Render Pipeline (URP)** for efficient 2D rendering

## Controls

| Key / Mouse                 | Action                                        |
| --------------------------- | --------------------------------------------- |
| **A**                       | Move left                                     |
| **D**                       | Move right                                    |
| **Space**                   | Jump                                          |
| **Enter** or **Left Click** | Fire a single shot (hold for continuous fire) |
| **CTRL**                    | Special action (try it out!)                  |
| **Escape**                  | Pause / return to editor (if implemented)     |
