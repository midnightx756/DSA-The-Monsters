# DSA-The-Monster

An endless sidescroller patformer game, comprising of bossfights and out of the blue mechanics.

Controls
A - move left
D Move right
Space - Jump
Enter/ left Click - fire 1 shot / Hold Fire multiple
CTRL - :) Just try the key for yourself.
